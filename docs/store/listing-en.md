## Description [10 000 characters]

A fast, keyboard-first, dual-pane file manager for Windows 11.

Plain Commander follows the classic two-panel design: two folders side by side, the cursor and the marks on the keyboard, every common action one key away: F5 copies, F6 moves, F7 creates a folder, F8 deletes. It is a native Windows 11 application with a quiet, modern look (light and dark theme) and handles archives, encrypted containers, FTP, SFTP and S3 servers, network shares, OneDrive, disk images, directory comparison and bulk renaming in the same two panels, with the same keys.

TWO PANELS, TABS, ONE KEYBOARD
Tabs in each panel, drive buttons, favorites, directory history, quick search by any fragment of a name, an editable path bar with breadcrumbs, a command line under the panels. Everything has a key; the mouse works too, including drag and drop between the panels and from or to File Explorer.

OPERATION QUEUE
Copy, move, delete, pack and unpack run in the background in a queue with progress, pause and cancel. Conflicts are decided per file (overwrite, skip, keep both, only if newer) with "apply to all"; errors offer retry or skip. A folder of 100,000 entries lists and sorts in about half a second.

UNDO
Ctrl+Z reverses the last copy, move, rename, Recycle Bin delete, new file or folder, attribute change, packing or encryption, after telling you exactly what will happen. An undo never deletes anything for good and never overwrites a file.

ARCHIVES AS FOLDERS
7z, zip, rar (including rar5 and multi-part), iso, cab, wim, tar, tar.gz, tar.zst, rpm, deb, dmg and more open like directories, with passwords. Write support for zip, 7z, tar and tar.gz. Search inside archives.

ENCRYPTION
Encrypt files and folders with a password into the program's own .pce container (AES-256-GCM, Argon2id key derivation, authenticated), which opens like an archive so you can browse it and copy single files out. 7z and zip with AES-256 are available for exchange with other programs.

SERVERS, NETWORK AND CLOUD
FTP, FTPS, SFTP and S3-compatible storage (Amazon S3, MinIO, Cloudflare R2, Wasabi, Backblaze B2) as ordinary folders, with resumable transfers and permission editing. Computers and shares on the local network, OneDrive folders (personal and work) and attached ISO or VHDX images are one click away in the drive menu.

COMPARE, SYNCHRONIZE, RENAME
Directory compare with a diff view, two-way synchronization with a preview, text and binary file compare, checksums. Bulk rename with masks, counters, search and replace, case changes and transliteration to Latin letters, with a preview and undo.

VIEW AND DETAILS
A built-in viewer for text (with encodings), hex and images; quick view in the other panel; optional columns with image dimensions, EXIF data, audio and video length, file version and folder sizes computed in the background; filters by name, extension, date and size.

LIGHT AND PRIVATE
No telemetry, no analytics, no update checks, no background services. The program connects only to the servers and shares you open. Passwords for servers are kept in the Windows Credential Manager. English and Polish interface.

Plain Commander is open source (Mozilla Public License 2.0).
