Encrypted .pce containers can now be kept on S3-compatible storage and changed there: open one with Enter and its password, copy single files in or out with F5, delete with F8. Only the changed file travels; the server sees neither names nor content. F5 on a .pce file towards S3 asks whether to keep it as a container or as a plain copy; Files → Encrypt can write straight to an s3:// folder. Large files go up and down in 8 streams. Fixed: a password or login dialog left open for more than 10 seconds no longer ends in "the disk did not respond". Containers on S3 need version 1.16 or later; .pce files on disk are unchanged.
