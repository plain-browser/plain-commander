Encrypted .pce files can now be changed in place: open one with Enter, copy files in with F5, delete with F8 and the file shrinks at once, without re-encrypting the rest. Change a .pce password from the Files menu. Files written by this version do not open in versions before 1.15; older .pce files still open and can be converted. Also new: command palette (Ctrl+Shift+P), reopen a closed tab (Ctrl+Shift+T), and name masks in copy and move (F5/F6), such as *.bak or old_*.*.
