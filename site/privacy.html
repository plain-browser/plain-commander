Polityka prywatności

Plain Commander jest menedżerem plików działającym w całości na Twoim komputerze. Program nie zbiera, nie przechowuje ani nie przesyła żadnych danych osobowych do autorów ani do kogokolwiek innego.

  • Brak telemetrii. Nie ma analityki, statystyk użycia, raportów błędów wysyłanych do sieci ani sprawdzania aktualizacji. Program nie łączy się z żadnym serwerem autorów.
  • Połączenia sieciowe tylko na Twoje polecenie. Program łączy się wyłącznie z serwerami (FTP, FTPS, SFTP, S3), udziałami sieciowymi i kontami OneDrive, które sam wskażesz. Dane są przesyłane bezpośrednio między Twoim komputerem a tym serwerem.
  • Hasła. Hasła do serwerów, jeśli zdecydujesz się je zapamiętać, trafiają do Menedżera poświadczeń systemu Windows na Twoim komputerze. Hasła szyfrowania plików nie są nigdzie zapisywane.
  • Ustawienia i dzienniki są zapisywane lokalnie w profilu użytkownika (%LOCALAPPDATA%) i nigdy nie opuszczają komputera.
  • Microsoft Store. Jeśli zainstalujesz program ze Sklepu Microsoft, Microsoft może przetwarzać dane o instalacji zgodnie z własną polityką prywatności; autorzy Plain Commandera nie mają do nich dostępu poza zbiorczymi statystykami pobrań.

Privacy policy

Plain Commander is a file manager that runs entirely on your computer. The program does not collect, store or transmit any personal data to its authors or to anyone else.

  • No telemetry. There are no analytics, usage statistics, crash reports sent over the network or update checks. The program never contacts a server of the authors.
  • Network connections only on your request. The program connects only to the servers (FTP, FTPS, SFTP, S3), network shares and OneDrive accounts you open yourself. Data travels directly between your computer and that server.
  • Passwords. Server passwords, if you choose to remember them, are stored in the Windows Credential Manager on your computer. File encryption passwords are never stored.
  • Settings and logs are kept locally in your user profile (%LOCALAPPDATA%) and never leave the computer.
  • Microsoft Store. If you install the program from the Microsoft Store, Microsoft may process installation data under its own privacy statement; the authors of Plain Commander see only aggregate download statistics.
